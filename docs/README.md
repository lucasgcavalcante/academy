# Introdução

O **Revodesk** é uma plataforma de **omnichannel** que centraliza a comunicação de empresas com seus clientes em múltiplos canais, oferecendo uma experiência unificada e eficiente. Com o Revodesk, é possível gerenciar mensagens de WhatsApp, redes sociais e outros canais de atendimento em um único lugar, automatizar processos, criar fluxos personalizados e gerar métricas de desempenho para otimizar o relacionamento com o cliente.

Esta documentação tem como objetivo guiar usuários, desenvolvedores e administradores na utilização da plataforma, explicando funcionalidades, integração via API, criação de fluxos e templates, configuração de usuários e canais, além de boas práticas para maximizar a eficiência do atendimento.
