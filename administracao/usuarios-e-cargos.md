# Usuários, cargos e permissões

Convide sua equipe e defina o que cada pessoa pode fazer no Revodesk.

{% hint style="info" %}
Tempo de leitura: 6 min · Para quem: gestores (administradores)
{% endhint %}

## Perfil e cargo: a diferença

Todo usuário tem um **perfil** e pode ter um **cargo**.

- **Perfil** é o nível de acesso base:
  - **Administrador**: acesso completo, incluindo Métricas e todas as Configurações.
  - **Atendente**: atende conversas e cuida dos contatos.
- **Cargo** é opcional e soma permissões extras a um atendente, como gerenciar etiquetas ou disparos. Você cria os cargos que fizerem sentido para a sua empresa.

## Cadastrando um atendente

1. No menu, clique em **Configurações** e depois em **Atendentes**.
2. Clique em **Novo atendente**.
3. Na janela **Adicionar usuário**, preencha:
   - **Nome** e **Email**.
   - **Perfil**: Administrador ou Atendente.
   - **Cargo**: um cargo personalizado ou **Nenhum (usar perfil padrão)**.
   - **Grupos**: marque os grupos de atendimento da pessoa.
4. Clique em **Adicionar**.

A pessoa recebe um convite por e-mail para definir a própria senha. Até aceitar, ela aparece com o status **Pendente**. Depois, **Ativo**.

<!-- PRINT: janela "Adicionar usuário" preenchida, com Perfil, Cargo e a lista de Grupos marcada -->

{% hint style="success" %}
O convite não chegou? Peça para a pessoa olhar a caixa de spam. Se precisar, use **Reenviar convite** no menu de ações (⋯) da linha.
{% endhint %}

## Editando e excluindo

No menu de ações (⋯) no fim da linha:

- **Editar**: muda os dados, o perfil, o cargo e os grupos. Há também o campo **Senha**: deixe em branco para manter a senha atual.
- **Excluir**: remove o usuário. Os atendimentos abertos dele vão para a fila.

{% hint style="warning" %}
Ao excluir um usuário, os dados dele são perdidos. Se a pessoa só vai se afastar por um tempo, avalie antes se excluir é mesmo o caminho.
{% endhint %}

## Criando cargos personalizados

1. Em **Configurações**, clique em **Cargos personalizados**.
2. Clique em **Novo cargo**.
3. Preencha o **Nome**, como "Supervisor" ou "Marketing", e, se quiser, a **Descrição**.
4. Em **Permissões**, marque o que esse cargo pode fazer.
5. Clique em **Adicionar**.

A lista de cargos mostra quantos usuários e quantas permissões cada um tem.

<!-- PRINT: janela "Novo cargo" com as permissões agrupadas por seção -->

### Permissões disponíveis

| Seção | Permissão |
| --- | --- |
| Conversas | Ver todas as conversas |
| Contatos | Gerenciar contatos (criar, editar, deletar) |
| Grupos | Gerenciar grupos (criar, editar, deletar) |
| Etiquetas | Gerenciar etiquetas (criar, editar, deletar) |
| Chatbots | Gerenciar chatbots (criar, editar, deletar) |
| Disparos | Gerenciar disparos (criar, editar, deletar) |

Depois, abra o atendente em **Atendentes** e escolha o cargo no campo **Cargo**.

{% hint style="warning" %}
As telas de administração (Canais de atendimento, Atendentes, Grupos, Cargos personalizados, Configurações gerais e Financeiro) e as Métricas da equipe ficam com os administradores. Para dar esse acesso a alguém, use o perfil **Administrador**.
{% endhint %}

### Editando ou excluindo um cargo

Use o menu de ações (⋯) na linha do cargo. Ao excluir, o Revodesk avisa quantos usuários estão vinculados a ele.
