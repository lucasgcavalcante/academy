# Encerrando e reabrindo atendimentos

Aprenda a finalizar um atendimento, o que acontece quando o cliente volta a falar e como retomar o contato com quem já foi atendido.

{% hint style="info" %}
Tempo de leitura: 3 min · Para quem: atendentes e gestores
{% endhint %}

## Encerrando um atendimento

Quando o assunto estiver resolvido:

1. Com a conversa aberta, clique em **Resolver**, no canto direito do cabeçalho.
2. A conversa vai para a aba **Encerrados** e a tela volta para a lista.

<!-- PRINT: cabeçalho da conversa com o botão Resolver em destaque -->

Também dá para encerrar pela lista: clique com o botão direito na conversa e escolha **Encerrar conversa**.

{% hint style="info" %}
**Resolver** e **Encerrar conversa** fazem a mesma coisa: finalizam o atendimento.
{% endhint %}

## Consultando atendimentos encerrados

1. Na lista, clique na aba **Encerrados**.
2. Clique na conversa para ver o histórico.

A conversa encerrada é só para leitura. O campo de mensagem fica bloqueado.

Outra forma de ver o histórico de um cliente é pelo painel **Dados do contato**, na seção **Conversas**, que lista os atendimentos anteriores dele.

## Quando o cliente volta a falar

Se o cliente mandar mensagem depois do encerramento, um **novo atendimento** é aberto automaticamente. Ele aparece na aba **Aguardando**, ou na aba **Automático** se a sua empresa usa um fluxo automático nesse canal.

## Retomando o contato com o cliente

Não existe um botão para reabrir um atendimento encerrado. Para voltar a falar com o cliente, inicie uma nova conversa:

1. Clique em **Nova conversa** e escolha o contato.
2. Siga o passo a passo de [Iniciando uma nova conversa](nova-conversa.md).

{% hint style="warning" %}
No canal WhatsApp, se a última mensagem do cliente tiver mais de 24 horas, a primeira mensagem precisa ser um template aprovado pela Meta. Essa é uma regra do canal.
{% endhint %}

## Outras saídas para uma conversa

- **Retornar**: devolve a conversa para a aba **Aguardando**, sem encerrar. Use quando outra pessoa deve continuar.
- **Deletar** (só administradores): apaga a conversa e todas as mensagens dela. O Revodesk pede confirmação.

{% hint style="warning" %}
Deletar não tem volta. Para tirar uma conversa da sua lista, prefira **Resolver**.
{% endhint %}
