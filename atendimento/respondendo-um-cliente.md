# Respondendo um cliente

Aprenda a aceitar um atendimento e a enviar texto, emoji, arquivos, áudio e respostas a mensagens específicas.

{% hint style="info" %}
Tempo de leitura: 5 min · Para quem: atendentes
{% endhint %}

## Aceitando o atendimento

Conversas novas chegam na aba **Aguardando**. Antes de responder, você precisa aceitar.

1. Abra a conversa na aba **Aguardando**.
2. No lugar do campo de mensagem aparece o aviso **Este atendimento está pendente. Aceite para responder.**
3. Clique em **Aceitar**.

A conversa passa para você e vai para a aba **Atendendo**.

<!-- PRINT: rodapé de uma conversa pendente com o aviso "Este atendimento está pendente. Aceite para responder." e o botão Aceitar -->

{% hint style="info" %}
Você também pode aceitar direto da lista: clique com o botão direito na conversa e escolha **Assumir conversa**. Essa é a forma de tirar uma conversa da aba **Automático** e atender você mesmo.
{% endhint %}

## Enviando uma mensagem de texto

1. Clique no campo **Digite uma mensagem**.
2. Escreva o texto.
3. Aperte **Enter** ou clique no botão de enviar.

Para pular uma linha sem enviar, use **Shift + Enter**.

O contador ao lado do botão mostra quantos caracteres você já usou. O limite é de 1.000 por mensagem.

<!-- PRINT: campo de mensagem com um texto digitado, mostrando a barra de ferramentas, o contador e o botão de enviar -->

## A barra de ferramentas

Embaixo do campo ficam os botões. Passe o mouse sobre cada um para ver o nome.

| Botão | O que faz |
| --- | --- |
| **Anexar** (+) | Envia **Imagem**, **Documento** ou **Áudio** do seu computador. |
| **Emoji** | Abre a lista de emojis. Clique em um para inserir no texto. |
| **Ativar / Desativar assinatura** | Liga ou desliga seu nome no topo das mensagens. |
| **Enviar template** | Envia uma mensagem pronta aprovada pela Meta. Só aparece em conversas do canal WhatsApp. |
| **Gravar áudio** (microfone) | Grava um áudio pelo microfone. Aparece quando o campo está vazio. |

## Assinatura

Com a assinatura ligada, cada mensagem sai com seu nome em negrito na primeira linha. Assim o cliente sabe quem está falando com ele.

Ela já vem ligada. Clique no ícone de pessoa para desligar ou ligar de novo. A escolha fica salva no seu navegador.

## Enviando arquivos

1. Clique em **Anexar** (+).
2. Escolha **Imagem**, **Documento** ou **Áudio**.
3. Selecione o arquivo no seu computador.
4. Confira a prévia com o nome e o tamanho do arquivo. Para desistir, clique no **X**.
5. Se quiser, escreva um texto em **Adicionar legenda...**.
6. Clique no botão de enviar.

Em **Documento** você pode enviar PDF, Word, Excel, TXT, ZIP e RAR.

<!-- PRINT: prévia de um arquivo anexado, com o nome, o tamanho, o campo "Adicionar legenda..." e o botão de enviar -->

{% hint style="success" %}
Copiou uma imagem? Cole com **Ctrl + V** dentro do campo de mensagem e ela entra como anexo.
{% endhint %}

## Gravando um áudio

1. Com o campo de mensagem vazio, clique no microfone (**Gravar áudio**).
2. Se o navegador pedir, permita o uso do microfone.
3. Fale. Um cronômetro mostra o tempo da gravação.
4. Clique no **✓ verde** para enviar ou no **X vermelho** para descartar.

{% hint style="warning" %}
Gravações muito curtas, com menos de um segundo, são descartadas sem aviso. Se o áudio não aparecer na conversa, grave de novo um pouco mais longo.
{% endhint %}

## Respondendo uma mensagem específica

Para deixar claro a qual mensagem você está respondendo:

1. Passe o mouse sobre a mensagem e clique na setinha no canto dela.
2. Escolha **Responder**.
3. A mensagem aparece acima do campo. Escreva e envie.

Para desistir, clique no **X** ao lado da mensagem citada.

## Quando o campo fica bloqueado

O campo de mensagem fica desativado em algumas situações:

- **Conversa no automático**: aparece **Esta conversa está em modo automático.** Assuma a conversa para responder.
- **Conversa encerrada**: aparece **Reabra ou aceite essa conversa para enviar uma mensagem.** Veja [Encerrando e reabrindo atendimentos](encerrando-atendimento.md).
- **Janela de 24 horas fechada (regra do canal WhatsApp)**: aparece **🔒 Janela fechada — utilize um template para iniciar o contato**.

{% hint style="info" %}
No canal WhatsApp, a Meta só permite mensagens livres até 24 horas depois da última mensagem do cliente. Passado esse prazo, use **Enviar template**. Quando o cliente responder, o campo de texto volta a funcionar. O passo a passo está em [Iniciando uma nova conversa](nova-conversa.md).
{% endhint %}
