# Respostas rápidas com /

Aprenda a usar textos prontos na conversa digitando uma barra e a cadastrar as suas respostas rápidas.

{% hint style="info" %}
Tempo de leitura: 3 min · Para quem: atendentes
{% endhint %}

<!-- VÍDEO: cole aqui o link do YouTube com {% embed url="..." %} -->

## O que são

Respostas rápidas são textos que você usa sempre: boas-vindas, horário de funcionamento, dados para pagamento. Cada uma tem um **atalho**, como `boas-vindas`. Na conversa, você digita `/` seguido do atalho e o texto entra no campo.

{% hint style="info" %}
As respostas rápidas são pessoais. Cada atendente vê e usa só as que ele mesmo cadastrou.
{% endhint %}

## Usando na conversa

1. No campo de mensagem, digite `/` e as primeiras letras do atalho. Por exemplo: `/bo`.
2. Aparece uma lista com as respostas que combinam, no formato `/atalho - começo do texto...`.
3. Escolha uma:
   - clique nela; ou
   - use as setas **↑** e **↓** e aperte **Enter**.
4. O texto completo entra no campo. Ajuste o que quiser.
5. Envie normalmente.

Para fechar a lista sem escolher, aperte **Esc**.

<!-- PRINT: campo de mensagem com "/bo" digitado e a lista de respostas rápidas aberta acima dele -->

{% hint style="success" %}
A resposta não é enviada sozinha: ela só preenche o campo. Aproveite para personalizar com o nome do cliente antes de enviar.
{% endhint %}

## Cadastrando suas respostas

{% hint style="warning" %}
A página **Respostas rápidas** ainda não aparece no menu do Revodesk. Para chegar nela, digite o endereço manualmente: na barra do navegador, troque o final do endereço por `/quick-messages` e aperte **Enter**. Exemplo: se você está em `https://seu-endereco/conversations`, vá para `https://seu-endereco/quick-messages`.
{% endhint %}

Dica: salve essa página nos favoritos do navegador para voltar com um clique.

1. Abra a página **Respostas rápidas**.
2. Clique em **Nova resposta**.
3. Preencha:
   - **Atalho**: a palavra que você vai digitar depois da barra. Por exemplo, `boas-vindas`. De 3 a 50 caracteres.
   - **Resposta**: o texto completo. De 3 a 500 caracteres.
4. Clique em **Salvar**.

<!-- PRINT: janela "Nova resposta rápida" com os campos Atalho e Resposta preenchidos -->

## Editando e excluindo

1. Na página **Respostas rápidas**, encontre a resposta. Use **Buscar por atalho ou texto** se a lista for grande.
2. Clique no menu **⋯** no fim da linha.
3. Escolha **Editar** ou **Excluir**.

A exclusão pede confirmação e não pode ser desfeita.
